# 預設包對照表 — 情緒/字眼 → 音效 + 運鏡 + 音樂

> 給 AI 讀的準則:節奏提案時,講到這類情緒/字眼,優先從這裡配。素材就在旁邊,不用再搜。
> **畫面上有動作(轉場、字幕進場、螢光筆、疊加卡片、推鏡…)要配什麼音效,查 `畫面動作×音效.md`**;這份管情緒/字眼跟音量。
> 用量依 SKILL 的 75 分預設:SFX 整支 3-6 個點,**每個都要落在畫面上看得到的動作**(第二行進場、轉場、卡片彈出;一般剪點不配),彩蛋類一支最多 1-2 個,不疊在同一拍。**兩行字幕的進場音效、轉場音效也算在這 3-6 個裡**(它們會自動寫進 `captions/sfx_cues.json`,`sfx_cues.py list` 看總數)。
> 音量欄是 ebur128 量的 LUFS + 建議起點 volume(以成品人聲 -14 LUFS 為基準:音效比人聲低 11-14dB、BGM 低 18-22dB 換算)。實際照這支影片的人聲再微調。
> **不要用 volumedetect 的 mean 挑音量** — mean 對中高頻音效會低報 5-6dB(學員實測:照 mean 配的音效比人聲還大聲)。量響度一律 `ffmpeg -i f.mp3 -af ebur128 -f null -` 看 Integrated I。

**★ 循環一定要用「可循環主體」那段,不要整檔 `-stream_loop`**:七首裡六首尾端有曲子自帶的淡出(近乎無聲的死區),整檔循環會把死區帶進成品中段、或剛好落在結尾字卡上讓音樂突然變超小聲(兩支已交付成品中招)。做法:`atrim=0:主體尾秒數` 之後再循環/`acrossfade` 接段,成品自己的結尾淡出用 `afade` 做(finalize.sh 已內建)。

**「目標 vibe」怎麼用**:那些歌是**版權商用歌**(她自己在影片裡也提醒 copyright)— render 出來的成品用會被判侵權,**不要下載、不要放**。它們只是幫你/使用者對齊「這種影片該是什麼感覺」,再挑上表的 royalty-free 檔去貼近那個感覺。使用者想要更像某首歌,就往那個調性挑更接近的預設檔,或請他自己丟一首 royalty-free 的進 `素材庫/背景音樂/`。

母庫 `素材庫/背景音樂/` 還有 lofi(通用預設款)。短曲用 `-stream_loop` 循環蓋滿全片。
**BGM 段落切換**:comedy 類不必墊整支 — 梗的那 10-20 秒切過去、講完切回主 BGM,反差就是笑點(交接 crossfade 0.5s)。
音量原則:目標 BGM 比人聲低 18-22dB。人聲跟 BGM 都用 ebur128 量 LUFS(不要用 volumedetect mean),上表只是起點;混完量一次成品 true peak,要 < -1dBTP。

## 運鏡(不用素材,GSAP 做,做法見 SKILL 5.1)

| 情緒/字眼 | 運鏡 | 可搭的音效 |
|---|---|---|
| 強調句:「真的」「超」「蠻扯的」、數字、金句 | punch-in 1.1-1.2x 快進慢出 | woosh / camera-shutter |
| 揭曉/反轉句 | step-zoom(瞬放緩回) | 前鋪 metallic-rise → 落 boom/hit |
| 情感句、慢段落 | 緩慢 creep-in(慢到沒感覺) | — |
| 梗/吐槽/自嘲 | 縮框(瞬縮露黑邊) | vine-boom / boom / womp-womp |
| 講到具體東西/流程 | 不用運鏡 → 用 b-roll 或圖卡 | 對應擬音(第 5 類) |

## 換片原則
- 這包是「起點不是終點」:使用者聽了不喜歡,就他自己丟檔案進來,選定後直接蓋掉同名檔(skill 照常引用)。
- 新增檔案就補這張表:什麼時候用 + 量到的音量。
