# 特效工具箱 — 給 AI 的調色盤

> 給 AI:這份是**工具**,不是規則。每支影片讀完腳本後,你判斷哪幾樣適合「這支的這幾句」,在節奏提案裡提出來、**每一項附一句為什麼**,使用者說好才做。
> 使用者想先看效果長什麼樣 → 請他雙擊 `tools/特效型錄/index.html`(每個工具都有範例片段)。型錄是**參考**,不是讓他先點菜;提案還是你出。

## 怎麼用這份(先讀這段)

- **沒有固定對應。** 不要「鉤子一律用開場字卡」「數字一律用重擊」。同一句話在不同人、不同影片,適合的工具不一樣。下面每個工具的「常見時機」只是提示。
- **挑少、挑準。** 一支 60 秒通常 2–4 個「大」工具就夠(開場字卡、重擊、頭後大字、動態 b-roll 算大的)。每個都放在最有力的那一句;同一拍只放一個,不要疊。
- **跨影片要有變化。** 提案前看 `專案筆記.md` / `我的剪輯偏好.md` 記的「上一支用了什麼」,不要支支都同一套。用完把這支用了哪些工具記進專案筆記。
- **他自己拍的畫面永遠優先,但動畫是預設配備。** 他有錄 b-roll、有拍現場,那一句就用他的;其餘在講步驟、數字、對話、情境的句子,預設就提動態 b-roll(一支 2-3 段),不要等他問「有沒有動畫」(2026-09-30 Jake 明講)。第 7 點是驗證過、可以直接套的範例。
- **跟其他提案放同一張清單,一次問完。** 學員回報過「問題太多」「分批問比較好」:工具提案不要另開一輪問,位置、字級、配色這種技術判斷不要問,做完講一句就好。
- **學員常以為特效要自己找檔案。** 他問「特效有更多嗎,還是要我自己抓?」→ 說明特效是程式做的、沒有數量限制,請他看 `tools/特效型錄/index.html`。
- **成本要講。** 每個工具下面有「成本」。要用到「去背」的工具,提案時說一句「這個要多跑一步,大約多 X 秒」。

## 共通規則(每個工具都適用,都是實測踩過的)

1. **時間掛在「審片鎖定的字幕句首」,不要逐字對時。** 逐字的時間戳不準(Whisper 字級時間會飄、音量波形切不開連續講話、拿幾秒的短片重跑 Whisper 會亂吐字)。大特效一律在「那句字幕開始的時間」落下 —— 那是使用者在審片時已經確認過的。需要對某個爆音(拍手、彈指)才用第 5.1 節「量輸出檔的音軌」的方法。
   **注意:句首 ≠ 開口。** 字幕句常常從換氣的空白開始(實測差 0.3 秒,推鏡照字幕放會「推完才講到重點」)。大特效落下前,用 5.1 的方法量一下那句開頭 0.5 秒的音量,真的開口比句首晚就往後挪到開口那一刻。
2. **重擊類只用在短的那幾個字,不要整句。** 整句一個字一個字砸,時間對不上、又蓋住臉,反而沒效果(實測)。整句話用一般字幕就好。
3. **不要蓋臉。** 大字放頭上方的空牆,或下巴以下。放之前擷取那一刻的影格看臉在哪。
4. **粗黑中文字體要自己指定**,英文字體沒有中文字,會退成細細的預設字(實測,看起來很弱):
   ```css
   @font-face { font-family:"CJKHeavy";
     src: local("FZLTTHB--B51-0"), local("Lantinghei TC Heavy"),   /* Mac:蘭亭黑-繁 特黑(有下載才有) */
          local("PingFangTC-Semibold"),                              /* Mac 內建 */
          local("MicrosoftJhengHeiBold"), local("Microsoft JhengHei Bold"); /* Windows 微軟正黑體 粗 */
     font-weight:100 900; }
   ```
   `font-family:"CJKHeavy","Source Han Serif TC VF","Source Han Serif TC",sans-serif;` —— 思源宋體是工具包安裝時就裝的,黑體都載不到時至少還是粗的宋體。
   記得加 `font-weight:900;`。**snapshot 看一眼字是不是真的粗黑**(log 裡的「Fonts FAILED」不準,以畫面為準)。蘭亭黑只有這台 Mac 實測過;PingFang / 微軟正黑體那兩行還沒在學員機器實測。學員回報過:**舊 Intel Mac 上字幕引擎抓不到蘋方**,設粗體也沒用 —— 碰到就改用思源宋體 900,或把那幾個大字用圖片做(跟封面同一套畫法)。
5. **字的大小用字數算,不要在 setup 量寬度**(字型可能還沒載入,量到的是錯的寬度,實測因此爆出畫面)。例:`el.style.fontSize = Math.min(190, 820 / 字數) + "px"`。
6. **長字幕要縮字級**:超過 12 個字的字幕,`font-size = 66 × 12 / 字數`,不然會偏一邊、被切掉(實測 14 字那句跑到右邊)。
7. **加完先 snapshot 再 render**:`npx hyperframes snapshot --at 秒數,秒數 --no-end`,看位置、有沒有出界、有沒有蓋臉。render 很貴,snapshot 幾秒。
   **設計類的畫面(動態 b-roll、自己畫的圖、大字、字卡)要先給學員看,他說好才 render。** 把那幾個關鍵時刻的 snapshot 用 ffmpeg 拼成一張圖(`hstack`)丟給他;沒做過的版面就先做幾秒的樣本。學員原話:「在你輸出影片檔前,先把生成好的圖片傳給我看」(那次連續 render 三輪整支影片才給他看,白燒三輪)。另一位學員:「先給排法表跟代表畫面,你看完直接說『鋪上去』這個方法好」。
8. **學員給了參考圖/參考影片 → 照著描,不要憑印象重畫。** 把他的參考圖放進畫面、你畫的東西半透明疊上去對齊,調到輪廓重合為止。學員原話:「我給你看了很多的範例,但你好像都沒有朝我給你的範例去走」(牙醫衛教圖改了五輪)。
9. **只改他點名的那一項。** 他說「牙根形狀不自然」就只改形狀,不要順手改長度 —— 自作主張延伸就是「越改越糟」的來源。
10. 所有元素照 composition 規則:`class="clip"` + `data-start` + `data-duration` + `data-track-index` + 唯一 id;tween 寫在同一條 `tl`;淡出後加 `tl.set(..., {opacity:0}, 結束前)` 硬關掉(lint 會抓)。

## 1. 開場字卡轟炸(stomp)

**是什麼:** 整段講話變成一張一張大字卡,在他頭上方「硬切」換下一張,背景微微壓暗。關鍵那張用紅字「砸」進來(放大+模糊+閃一下再落定)。這段時間不顯示一般字幕,字卡就是字幕。
**感覺:** 很衝、很有節奏,像廣告開頭。
**常見時機(參考):** 開頭幾秒的鉤子;整支最有力的一句宣言。句子要短,長句會變成一大串卡片。
**成本:** 不用去背,跟一般字幕一樣便宜。

**做法:** 每 1–2 個詞一張卡(用審片鎖定的字幕句,把句子切成詞;每張卡的時間 = 那句的句首往後依字數比例分)。
```html
<div id="hookdim" class="clip" data-start="0" data-duration="9.8" data-track-index="9"
     style="position:absolute; inset:0; z-index:2; background:#05070c; opacity:0;"></div>
<div id="stomp" class="clip" data-start="0" data-duration="9.6" data-track-index="10"
     style="position:absolute; left:0; top:0; width:100%; z-index:6; pointer-events:none;">
  <div class="scard" id="k0">這支影片</div>
  <div class="scard hot" id="k1">AI 剪的</div>
  ...
</div>
```
```css
.scard { position:absolute; opacity:0; white-space:nowrap; font-family:"CJKHeavy","Source Han Serif TC VF",sans-serif; font-weight:900;
  line-height:1; color:#F5F1E8; text-shadow:0 4px 26px rgba(0,0,0,.65); }
.scard.hot { color:#FF5C39; text-shadow:0 0 34px rgba(255,92,57,.45), 0 4px 26px rgba(0,0,0,.65); }
```
```js
// CARDS: [{id, txt, inn, out, hot, hero}],inn/out = 秒數;hero = 最重要那張(一段最多一張)
const ANCH = [[540,330],[512,302],[568,358],[540,388],[518,336]];   // 直式:頭上方空牆,每張微微錯位
tl.fromTo("#hookdim", { opacity: 0 }, { opacity: 0.4, duration: 0.25 }, 0.05);
tl.to("#hookdim", { opacity: 0, duration: 0.3 }, 段落結束 - 0.15);
CARDS.forEach((c, ci) => {
  const el = document.getElementById(c.id);
  el.style.fontSize = Math.min(190, 820 / el.textContent.replace(/\s/g, "").length) + "px";
  const [ax, ay] = ANCH[ci % ANCH.length];
  gsap.set(el, { left: ax, top: ay, xPercent: -50, yPercent: -50, rotation: (ci % 2 ? -1 : 1) * (0.8 + (ci % 3) * 0.7) });
  if (c.hero) {            // 砸進來:放大 2.6 + 模糊 + 過曝 → 落定 → 壓扁回彈;背景瞬間更暗
    tl.set("#hookdim", { opacity: 0.62 }, c.inn);
    tl.to("#hookdim", { opacity: 0.4, duration: 0.5 }, c.inn + 0.12);
    tl.set(el, { opacity: 1, scale: 2.6, filter: "blur(10px) brightness(2.6)" }, c.inn - 0.04);
    tl.to(el, { scale: 1, filter: "blur(0px) brightness(1)", duration: 0.11, ease: "power4.in" }, c.inn - 0.04);
    tl.set(el, { scaleX: 1.10, scaleY: 0.92 }, c.inn + 0.07);
    tl.to(el, { scaleX: 1, scaleY: 1, duration: 0.45, ease: "elastic.out(1.05, 0.36)" }, c.inn + 0.15);
  } else if (c.hot) {      // 紅字彈一下
    tl.set(el, { opacity: 1, scale: 1.18 }, c.inn);
    tl.to(el, { scale: 1, duration: 0.22, ease: "back.out(1.8)" }, c.inn + 0.02);
  } else {                 // 一般卡:硬切出現 + 慢慢放大
    tl.set(el, { opacity: 1, scale: 1 }, c.inn);
    tl.to(el, { scale: 1.1, duration: Math.max(0.2, c.out - c.inn), ease: "none" }, c.inn);
  }
  tl.set(el, { opacity: 0 }, c.out);
});
```
這段時間要把一般字幕拿掉(不要同時出現)。

## 2. 重點重擊(loud slam)

**是什麼:** 一句話裡最重的那幾個字,超大、亮黃,一個字一個字「砸」下來(放大+歪一下→落定),停一下再收掉。
**感覺:** 強調、有力,像 MV 的歌詞重拍。
**常見時機(參考):** 整支的轉折句、結論句裡最短的那個重點(例:「真的拿回來」)。**只用那幾個字**,前後的句子照一般字幕。
**成本:** 不用去背,很便宜。

```html
<div id="slam" class="clip" data-start="句首秒數" data-duration="該句長度" data-track-index="11"
     style="position:absolute; left:0; top:0; width:100%; z-index:7; pointer-events:none;">
  <div style="position:absolute; left:60px; width:960px; top:1190px; text-align:center;">   <!-- 下巴以下;先看影格確認 -->
    <div class="slamline"><span class="lc">真</span><span class="lc">的</span><span class="lc">拿</span><span class="lc">回</span><span class="lc">來</span></div>
  </div>
</div>
```
```css
.slamline { font-family:"CJKHeavy","Source Han Serif TC VF",sans-serif; font-weight:900; font-size:168px; line-height:1.1; color:#FFD400;
  white-space:nowrap; text-shadow:0 3px 0 rgba(0,0,0,.35), 0 8px 26px rgba(0,0,0,.6); }
.lc { display:inline-block; opacity:0; }
```
```js
// 整組在句首一次落下(字與字間隔 0.035 秒,0.2 秒內全部到位)—— 不要試著對每個字的發音
tl.fromTo("#slam .lc", { opacity: 0, scale: 1.6, y: -30, rotation: (i) => (i % 2 ? -5 : 5) },
  { opacity: 1, scale: 1, y: 0, rotation: 0, duration: 0.2, ease: "back.out(1.8)", stagger: 0.035 }, 句首);
tl.fromTo("#slam .slamline", { scale: 1 }, { scale: 1.07, duration: 1.0, ease: "power1.out" }, 句首 + 0.25);
tl.to("#slam .slamline", { opacity: 0, y: -24, duration: 0.15 }, 句尾 - 0.2);
tl.set("#slam .slamline", { opacity: 0 }, 句尾 - 0.03);
```
那一句的一般字幕拿掉。

## 3. 頭後大字(字在頭的後面)

**是什麼:** 一兩個關鍵字變成超大字,放在他**頭的後面**(頭髮擋住字的下半部),背景微暗,像電影海報。
**感覺:** 電影感、質感,很吸睛。
**常見時機(參考):** 情緒最高點的那個詞(例:「頭很痛」)、最想讓人記住的數字(例:「兩個小時」)。一支 1–2 個就夠,多了就不稀奇。
**成本:** **要去背**(把人從背景切出來)。第一次用會下載一個約 168MB 的模型(只下載一次)。只切那 1–2 秒,很快;整支 24 秒約 75 秒(M 系列 Mac 實測)。Windows 還沒實測。**舊電腦(Intel、8GB)去背會慢很多**(學員裡有 2017 Intel i5 / 8GB 的機器):那種機器上就不要提,或只切 1–2 秒。
**限制:** 背景越單純、頭髮邊越清楚,效果越好;背景很亂(店裡很多東西)要先試一段看邊緣。那幾秒主畫面不能在做縮放/平移(不然人跟字會對不上)。

**做法:** 疊的順序 = 主畫面(z1)→ 壓暗層(z2)→ 大字(z3)→ 切出來的人(z4)→ 字幕(z20)。
```bash
# 只切需要的那一段(T0 = 大字出現的秒數、DUR = 停留秒數),從「目前這版 preview」切,時間才會對上
ffmpeg -y -ss T0 -i 工作檔/preview_vN.mp4 -t DUR -c:v libx264 -crf 12 -an 工作檔/captions/assets/_seg1.mp4
npx hyperframes remove-background 工作檔/captions/assets/_seg1.mp4 -o 工作檔/captions/assets/_fg1.mov
ffmpeg -y -i 工作檔/captions/assets/_fg1.mov -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 18 -auto-alt-ref 0 -an 工作檔/captions/assets/fg1.webm
```
(實測路徑是 .mov → 轉成透明 webm;直接輸出 .webm 沒測過。)
```html
<div id="dim1" class="clip" data-start="T0" data-duration="DUR" data-track-index="6"
     style="position:absolute; inset:0; z-index:2; pointer-events:none;
            background:radial-gradient(90% 60% at 50% 35%, rgba(0,0,0,.15) 0%, rgba(0,0,0,.62) 100%);"></div>
<div id="emb1" class="clip" data-start="T0" data-duration="DUR" data-track-index="7"
     style="position:absolute; left:0; top:0; width:100%; z-index:3; pointer-events:none;">
  <div id="w1" style="position:absolute; left:0; width:1080px; top:300px; text-align:center; white-space:nowrap;
       font-family:'Source Han Serif TC VF','Source Han Serif TC',serif; font-weight:900; font-size:330px; line-height:1;
       color:#ff3b30; text-shadow:0 0 40px rgba(255,59,48,.55), 0 10px 30px rgba(0,0,0,.45);">
    <span style="display:inline-block">頭</span><span style="display:inline-block">很</span><span style="display:inline-block">痛</span></div>
</div>
<video id="fg1" class="clip" src="assets/fg1.webm" muted playsinline data-start="T0" data-duration="DUR" data-track-index="8"
       style="position:absolute; inset:0; width:100%; height:100%; object-fit:cover; z-index:4;"></video>
```
```js
tl.fromTo("#dim1", { opacity: 0 }, { opacity: 1, duration: .2 }, T0);
tl.fromTo("#w1 span", { opacity: 0, y: -160, scale: 1.7, filter: "blur(18px)" },
  { opacity: 1, y: 0, scale: 1, filter: "blur(0px)", duration: .26, ease: "power4.out", stagger: .11 }, T0 + .02);
tl.to("#w1", { scale: 1.06, duration: .75, ease: "sine.out" }, T0 + .4);
tl.to("#w1", { opacity: 0, y: -60, filter: "blur(14px)", duration: .22 }, T0 + DUR - .25);
tl.to("#dim1", { opacity: 0, duration: .2 }, T0 + DUR - .23);
```
**位置:** 大字的 `top` 要讓頭髮蓋住字的下面約 1/3,中間的字要還看得出來。先 snapshot:頭把中間的字整個擋掉 → 往上移。
**字級:** 3 個字 ~330px、4 個字 ~250px(寬度不超過 1000px)。
**顏色:** 情緒類紅 `#ff3b30`、數字/重點類黃 `#FFD400`。這一拍一般字幕照常顯示(小的、可讀),大字就是強調,不要再加圈、底線。

## 4. 字幕強調三種(小、便宜、常用)

**是什麼 / 感覺:** 在一般字幕上做一點變化,讓那句突然「不一樣」。
- **手繪圈** —— 紅筆把一個詞圈起來(像老師批改)。
- **手繪底線** —— 黃色筆刷在詞下面畫一條線,詞彈一下。
- **整框翻色** —— 整個字幕框瞬間變黃底黑字、彈一下(最「突然」)。
**常見時機(參考):** 不值得動用大工具、但想讓人多看一眼的詞。一支挑 2–4 個,跟 `kw` 塗黃算同一個額度;已經有大工具的那一拍不要再加。
**成本:** 幾乎零。

```html
<!-- 手繪圈:包住那個詞 -->
<span class="mark circle"><span class="t">頭很痛</span><svg viewBox="0 0 260 110" preserveAspectRatio="none"><path id="ring1"
  d="M34 30 C 70 6, 200 4, 240 34 C 268 58, 236 98, 150 104 C 70 108, 14 92, 12 62 C 10 38, 44 22, 96 16"
  fill="none" stroke="#ff3b30" stroke-width="7" stroke-linecap="round" vector-effect="non-scaling-stroke"/></svg></span>
<!-- 手繪底線 -->
<span class="mark under"><span class="t kw" id="kw1">兩個小時</span><svg viewBox="0 0 300 26" preserveAspectRatio="none"><path id="under1"
  d="M4 16 C 60 6, 120 22, 180 12 S 270 8, 296 14" fill="none" stroke="#FFD400" stroke-width="7"
  stroke-linecap="round" vector-effect="non-scaling-stroke"/></svg></span>
```
```css
.mark { position:relative; display:inline-block; }
.mark .t { position:relative; z-index:2; }
.mark svg { position:absolute; z-index:1; overflow:visible; pointer-events:none; }
.mark.circle svg { left:-22%; top:-38%; width:144%; height:176%; }
.mark.under svg  { left:-4%; bottom:-30px; width:108%; height:26px; }   /* -30px:太靠上會劃過字(實測) */
```
```js
// 線條先藏起來(setup 時做一次)
["#ring1", "#under1"].forEach(sel => { const p = document.querySelector(sel); const L = p.getTotalLength();
  gsap.set(p, { strokeDasharray: L, strokeDashoffset: L }); });
tl.to("#ring1",  { strokeDashoffset: 0, duration: .45, ease: "power2.out" }, 那個詞的句首 + 一點);
tl.to("#under1", { strokeDashoffset: 0, duration: .45, ease: "power1.inOut" }, 同上);
tl.fromTo("#kw1", { scale: 1 }, { scale: 1.12, duration: .14, ease: "back.out(3)", yoyo: true, repeat: 1 }, 同上);
// 整框翻色:給那句的 .sub-inner 一個 id
tl.fromTo("#flip1", { backgroundColor: "rgba(0,0,0,0.72)", color: "#ffffff", scale: 1 },
  { backgroundColor: "#FFD400", color: "#111111", scale: 1.12, duration: .16, ease: "back.out(2.5)" }, 句首 + .05);
tl.to("#flip1", { scale: 1, duration: .3, ease: "power2.out" }, 句首 + .21);
```
詞在句尾時,圈/底線落在「句首 + 句長 × 詞前面的字數 / 總字數」附近就好,提早一點比晚好。

## 5. 人縮成卡片 / 角落子母畫面(畫面讓位)

**是什麼:** 主畫面(他本人)縮小成圓角卡片或角落小窗,讓出空間給動態 b-roll 或說明面板;講完再放大回來。
**感覺:** 「畫面在幫他說明」,人還在,但舞台讓給內容。
**常見時機(參考):**
- 縮成中間卡片:他的**表情就是重點**、但想加畫面放大情緒的時候(例:抱怨很痛苦 → 周圍堆滿雜事)。
- 角落小窗:比較長(4 秒以上)的說明,不想讓觀眾忘記是誰在講。
- **不用縮、直接整個蓋掉也可以**:純說明、他的臉沒有加分的時候(流程、數字、圖表)。三種依那一刻判斷,不要支支都縮。
**成本:** 很便宜。

```js
// 主畫面 id 是 #a-roll。縮之前要有一層「舞台背景」clip 在它下面(z-index 0),不然露出的是黑底
gsap.set("#a-roll", { transformOrigin: "50% 50%", borderRadius: 0 });
// 縮成中間卡片
tl.to("#a-roll", { scale: .5, y: -80, borderRadius: 64, boxShadow: "0 30px 80px rgba(0,0,0,.6)", duration: .5, ease: "power3.inOut" }, T);
// 縮到左上角小窗
tl.to("#a-roll", { scale: .26, x: -340, y: -480, borderRadius: 160, boxShadow: "0 18px 40px rgba(80,50,20,.35)", duration: .5, ease: "power3.inOut" }, T);
// 放回全螢幕
tl.to("#a-roll", { scale: 1, x: 0, y: 0, borderRadius: 0, boxShadow: "0 0 0 rgba(0,0,0,0)", duration: .45, ease: "power3.inOut" }, T2);
```
舞台背景(深色、或米白點點)=一個全畫面 `<div class="clip">` z-index 0,時間蓋住縮小的那段。
字幕位置(下方 340px)不動;縮小的卡片放在字幕上方,別壓到字幕。

## 6. 動態 b-roll(預設配備:用動畫把那句話「演」出來)

**是什麼:** 幾秒鐘的動畫畫面,把他正在講的事情用圖像演出來;人聲照播。可以搭配第 5 點(人縮小/角落)或整個蓋掉。
**感覺:** 看得懂、有質感,像產品發表會的說明動畫。
**常見時機(參考):** 他在**解釋一件事**(流程、步驟、前後差別)、**講一個數字**、**轉述他跟客人講的話**,或**情緒需要被放大**(很煩、很亂、很爽)的時候。那一句他有真的畫面就用畫面,沒有就用這個 —— 預設就提,不用等他問。
**成本:** 不用去背;多一點 token(要寫動畫)。每段 3–9 秒。

**內容一定從他講的話來、從他的行業來,不要每個學員都同一套。** 專業內容(醫療、解剖、產品結構)要畫得對:先問他有沒有參考圖,照第 8 條描;先給他看靜態圖再做動畫。 例:講「很亂」—— 剪輯講師是「想拍的影片便利貼 + 剪輯錯誤通知」;美甲店是「LINE 訊息一直跳 + 預約撞期」;餐廳是「外送單一直印出來」。

驗證過的兩種骨架(完整可跑的程式碼在 `tools/特效型錄/範例-動態b-roll.html`,照抄改內容):

**A. 情緒堆疊(overwhelm)** —— 東西一個一個彈出來、越堆越多、從四面八方逼近,最後一口氣全部掉下去(或用推鏡把它們推開)。
- 人縮成中間卡片 → 便利貼(他的待辦/想做的事)彈進來、每張微微歪 → 紅色警示通知從四周滑進來 → 整堆抖一下 → 全部往下掉、人放回全螢幕。
- 所有位置先寫死(不用 random),便利貼 `back.out` 彈入、通知 `power3.out` 滑入、掉落 `power2.in`。

**B. 流程說明面板(AI/系統在工作)** —— 一個白色面板,裡面的東西「自己在做事」:狀態膠囊(轉圈圈 + 「處理中…」→ 換下一個狀態 → 綠勾「完成」)、清單一行一行打字出來、壞掉的那行變紅劃掉再收起來、剩下的打勾。
- 適合「它會先…然後…接著…最後…」這種步驟句:每個步驟的句首換一次狀態。
- 狀態轉圈一定是有限次數(`rotation: 720, duration: 2`),不可以無限重複。

**其他常見形狀(沒寫好範例,要自己寫):** 數字跳動(以前 → 現在)、左右對比(before / after)、訊息一直跳(LINE/IG 私訊)、行事曆被預約填滿、清單打勾。原則一樣:位置寫死、進場有節奏、跟著句首換拍、結尾收乾淨。

## 7. 驗證過的動畫範例(可以直接套,選段demo 2026-09-29)

全部在真片上 render 過(`我的影片/選段demo-客人不肯入鏡/工作檔/captions/creative.py` 是完整原始碼)。**內容一律換成這支影片他講的事**,不要原封不動搬。共通做法:特效層寫成 `creative.py`,讀 gen_captions 產的 `base.tpl` 注入 → 產 `index.html`,之後重產字幕不會洗掉特效。「人縮小」都要先鋪一層舞台背景(第 5 點)。

### 7a. 數字「發生」:一排小人,N 個變紅
**用在:** 講比例、機率、「十個有九個」。比只寫出 90% 有感很多。
- 人縮成下方卡片(scale .5、y +250),上方一排 10 個小人(SVG 圓頭 + 圓角身體,`color:currentColor` 才能整個變色)。
- 開場 0.25 秒起一個一個跳進來(`back.out`,間隔 0.05)。
- 講到數字那句的句首:照「打散的順序」(不要從左到右,像隨機但寫死)每 0.09 秒變一個紅 + 左右搖頭 + 白色 ✕,剩下的變綠 + ✓。同一拍下 hit。
```js
const order = [0, 9, 3, 7, 1, 5, 8, 2, 4];          // 寫死,不要 Math.random
order.forEach((k, j) => { const t = T + j * 0.09;
  tl.to("#p" + k, { color: "#E5484D", duration: 0.08 }, t);
  tl.fromTo("#p" + k, { rotation: 0 }, { rotation: j % 2 ? -12 : 12, duration: 0.08, yoyo: true, repeat: 3 }, t);
  tl.to("#p" + k + " .mk", { opacity: 1, duration: 0.06 }, t); });
```

### 7b. 對話框逐字打出他講的話
**用在:** 他轉述「我會跟客人說……」、私訊怎麼回、預約時講什麼。內容一律照他原話。
- 人縮成下方小窗(scale .36、y +360),上方一個米白對話框:頂部一條「客人」、中間一顆系統訊息(例:預約完成)、右邊他的泡泡逐字打出、最後客人回一顆小泡泡(OK ✓)。
- 逐字打用一個數字 tween 驅動,**有限時間、可 seek**:
```js
const TYPED = "對了，我們當天可能會有一個拍攝環節，OK 嗎？", tEl = document.getElementById("typed"), typer = { n: 0 };
tl.fromTo(typer, { n: 0 }, { n: TYPED.length, duration: 3.0, ease: "none",
  onUpdate: () => { tEl.textContent = TYPED.slice(0, Math.round(typer.n)); } }, 句首);
```
- 對話框高度照內容量抓,**不要留半框空白**(第一版 640px 下半空一片,縮到 560 才好看)。

### 7c. 真實畫面切換 + 紅圈跟著人走
**用在:** 他講到「我後面那個人」「這台機器」,原片裡剛好拍得到。比任何動畫都有說服力。
- 原片是 4K、成品裁成特寫時:用**同一份 edl.json 換來源**(較寬的裁切)再 render 一次 → 得到時間完全對齊的寬畫面版;用 `<video data-media-start="句首" data-start="句首">` 切那 2 秒。
- 紅圈用 SVG `<ellipse>`,`strokeDashoffset` 畫出來;被圈的人在走,就 tween `attr:{cx}` 跟著走(先抽 3 格量他的位置)。旁邊一顆紅色標籤(「攝影夥伴」)。
- **寬畫面會帶進別人的臉**:先看影格,邊緣有旁人就蓋一塊 `backdrop-filter:blur(22px)`。

### 7d. 清單逐條打勾(講「第一、第二、第三」)
**用在:** 他分點講。每一點的句首亮一次(目前這點金色、講完的綠勾、還沒講的淡色),亮 2-3 秒就收,不要整支掛著。
- ⚠ **①②③ 這種圈號在粗黑字型裡沒有字**,會退成小小的「1)」。改用圓框 + 數字:`<span class="tick n">1</span>`(`border:3px solid currentColor; border-radius:50%`),完成的換 `<span class="tick y">✓</span>`(綠底白勾)。

### 7e. 心虛版:瞬間縮小變灰 + 紅章
**用在:** 他在**模仿錯誤示範**(心虛的語氣、客人的抱怨)。模仿開始的那個字瞬縮,講到「不要這樣」瞬間彈回。
```js
tl.set("#a-roll", { scale: 0.78, filter: "grayscale(1) brightness(.9)", borderRadius: 30 }, 模仿開始);
tl.fromTo("#shy", { opacity: 0, scale: 1.8 }, { opacity: 1, scale: 1, duration: 0.16, ease: "power4.in" }, 模仿開始 + .06);
tl.set("#shy", { opacity: 0 }, 不要這樣); tl.set("#a-roll", { scale: 1, filter: "grayscale(0) brightness(1)", borderRadius: 0 }, 不要這樣);
```
用 `set` 不用 `to`:突然才好笑(同第 5.1 節縮框)。

### 這批踩到的坑
- **整框翻色(第 4 點)遇到塗黃的關鍵字**:框變黃底,黃字就消失。翻色那一拍要把 `.kw` 一起改色(例 `#B3261E`)。
- **手持鏡頭又裁成特寫**:放大前從整支抽 10-12 格確認人沒被晃出框;臉的高度會飄(這支在畫面 25%-47% 之間),字卡要避開整段的範圍,不是只看一格。
- **超過 12 字的字幕**會溢出字幕框:gen_captions 現在會自動縮那幾句,特效層不要再自己改字級。
